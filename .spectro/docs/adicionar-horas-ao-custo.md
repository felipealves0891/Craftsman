# Adicionar valor das Horas ao custo

## Contexto

Hoje temos um relatorio basico na tela de finanças.

## Objetivo

Adicionar o valor das horas trabalhadas aos custos. No produto temos a quantidade de horas gastas para produção, agora temos que adicionar no appsetings o valor hora e quando for fazer o calculo adicionar a quantidade de horas x o valor hora.
