# Architecture Tasks

## Objetivo
Melhorar a usabilidade das telas de pedido, hoje temos 3 telas diferentes para o gerenciamento de pedidos:

- Listagem
- importação
- Criação de pedido (Pedido manual)

A criação de pedidos, pode ficar em uma tela separada, mas precisamos evoluir a usabilidade dela. Por exemplo, hoje eu só consigo adicioar 3 produtos, não faz sentido. Precisamos de um botão para adicionar uma nova linha.

## Tarefas

### Evoluir front end

- [x] Adicionar link para novo pedido da listagem de pedidos
- [x] Remover o dropdown do menu pedido e adicionar um botão para Pedidos
- [x] Precisamos poder adicionar mais produtos no pedido, quando o usuario preencher a ultima linha do produto, deve ser adicionada uma nova e sempre iniciar com uma unica linha.
- [x] O vinculo com o produto interno deve ser melhorado, podemos ter sentenas de produtos
- [x] Ajustar as dimensões das telas, e aplicar as novas cores 
- [x] Adicionar botão de voltar da tela do novo pedido para listagem de pedidos
- [x] Adicionar tabs com Itens, Produção e Envios na tela de detalhes

Critérios de aceitação:
