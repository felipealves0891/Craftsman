## Tela de login com layout anonimo

### Criterios de aceitacao
- A tela de login deve usar um layout proprio para telas sem autenticacao.
- O layout anonimo nao deve exibir sidebar, topbar, menu de usuario ou footer do layout autenticado.
- As views anonimas da pasta `Views/Account` devem usar o layout anonimo por padrao.
- A validacao client-side da tela de login deve continuar funcionando.
